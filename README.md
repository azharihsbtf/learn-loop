# LearnLoop

A self-directed learning tracker with AI-generated quizzes and spaced repetition.

**Status:** early build — setup instructions, architecture diagram, and live demo link will land here as the project progresses.

## Stack

FastAPI + Next.js + PostgreSQL (Neon) + Redis (Upstash) + Groq LLM.
See `/docs` for full planning documents.
